# Valid

> Valid (valid.co) is an AI-native advertising agency that grows consumer companies through an end-to-end performance marketing offering: AI-generated performance creative (20+ ads per month, concept to launch in about 3 days), brand-specific AI-influencers with organic followings, and multi-platform media buying across Meta, TikTok, Google, Snap, and AppLovin. Backed by Canaan Partners. Based in San Francisco, California. Valid has no public developer program, but it does run a live first-party MCP server — the "Chat With Your Ads" server — bundled into every managed media-buying engagement and reachable only by Valid clients.

## Agent surface

- [Chat With Your Ads MCP Server](https://mcp.valid.co/api/mcp/): Model Context Protocol endpoint (JSON-RPC over streamable HTTP) that lets a client query their whole ad account in plain English. **Auth-gated** — an anonymous `tools/list` returns HTTP 401 `{"detail":"Not authenticated"}` with `WWW-Authenticate: Bearer`, so the tool catalog is not public.
- [OAuth 2.0 Protected Resource Metadata](https://mcp.valid.co/.well-known/oauth-protected-resource): RFC 9728 document naming the resource, its authorization server, and scopes. HTTP 200, anonymous.
- [OAuth 2.0 Authorization Server Metadata](https://mcp.valid.co/.well-known/oauth-authorization-server): RFC 8414 document — authorization code + refresh token grants, PKCE (S256 and plain), dynamic client registration (RFC 7591), scopes `openid` `email` `profile`. HTTP 200, anonymous.
- Access: obtain a bearer token via the authorization code flow at https://mcp.valid.co/oauth/authorize and https://mcp.valid.co/oauth/token. A Valid client account is required; there is no self-serve signup for the API.

## What is NOT published

- No developer portal, API reference, or documentation site (docs.valid.co, developers.valid.co, developer.valid.co all NXDOMAIN).
- No OpenAPI or Swagger. The MCP host runs FastAPI, but `/openapi.json`, `/docs` and `/redoc` are behind an API-key gate (HTTP 407).
- No MCP tool catalog, no `llms.txt` served by Valid (`/llms.txt` is 404 on valid.co, 407 on mcp.valid.co).
- No A2A agent card, no SDKs or client libraries in any package registry, no public GitHub organization.
- No pricing page, no rate limits, no status page, no changelog, no SLA, no versioning or deprecation policy.
- api.valid.co is a Kong gateway with no publicly routed paths — every request returns `{"message":"no Route matched with those values"}`.
